En C, `a % n` a le signe de `a`. Pour `a = -7`, `n = 3`, on obtient -1, qui
n'est pas dans l'intervalle voulu `[0, 3)`.

Il suffit d'ajouter `n` UNE fois quand le reste est négatif :
  -7 % 3 = -1  ->  -1 + 3 = 2.

Enregistre le reste dans une variable, et renvoie `r < 0 ? r + n : r`.
Comme `r` est forcément dans `(-n, n)`, un seul ajout suffit toujours.
